## 3. 資產(淨資產)

預設首頁。**淨資產 = 流動資金 + 投資市值 − 負債**(美金 / 加密以匯率換算)。手風琴式一次展開一類。

- **最上方「我的淨資產」**:下方顯示**今日漲跌額與比例**(紅漲綠跌)。**點一下**進入**淨資產長條圖頁**:
  - 可切換 **淨資產 / 漲幅** 兩種長條圖
  - X 軸可選 **天 / 週 / 月 / 年**:天顯示 7 天、週 5 週、月 12 個月、年 10 年
  - 淨資產長條為藍色;漲幅長條紅漲綠跌
- **流動資金**:可建立多個現金帳戶(台幣 / 美金);點帳戶可改名稱、幣別、餘額,並有「快速增減」存入 / 提出
- **投資**:即現有持倉市值;可建立**群組**(單層,例:ETF、核心持股),持倉可入組或獨立;點群組進入**群組詳情頁**;點持倉可指定群組
- **期貨**(台指期):有期貨交易或已連結保證金帳戶時出現。金額＝**權益數**(保證金帳戶餘額＋未平倉損益),保證金帳戶會從流動資金搬到這張卡內。點卡進入期貨頁:
  - **風險指標**＝權益數 ÷ 原始保證金,色條標出砍倉線(25%)與追繳線(維持÷原始),並換算成「再跌幾點追繳 / 砍倉」
  - **帳戶槓桿**＝契約總值 ÷ 權益數;**整體曝險**＝(股票市值＋契約總值) ÷ 淨資產（股票全投入時約 1.0×＋期貨部分）
  - 部位卡(大台 / 小台 / 微台,多空皆可)→ **轉倉**(填平倉價、轉到月份、新倉價,一次產生兩筆)、**平倉**、**入出金**
  - 右上角走勢 icon → 權益數走勢 / 月漲幅 / 交易紀錄(轉倉合併一列顯示價差);⋯ → 設定(保證金帳戶、期交所保證金金額、手續費 / 口、提醒)
  - 保證金金額每日自動抓期交所公告,也可手改;到期前 7 天與風險指標低於 100% 會推播提醒
  - 平倉 / 轉倉的已實現損益、手續費、期交稅(契約值 × 0.002%)會自動記入保證金帳戶;期貨損益併入淨資產、每日快照、報表與統計
- **負債**:可建立多筆(信貸、房貸…),以負值計入淨資產
- **買賣連動**:新增交易時可選「現金帳戶」——買入自動扣款、賣出自動存入(依標的幣別過濾帳戶;也可選不使用);編輯 / 刪除交易會自動沖銷
- 現金帳戶 / 負債 / 群組皆隨雲端同步與 CSV 備份

> **佔比基準**(群組 / 持倉百分比的分母:`組內 / 投資 / 淨資產`)在「**設定 → 顯示設定**」調整。

## 4. 投資(持倉)

顯示總覽與持倉明細。

- **總覽卡**:總倉位、今日損益、總損益、報酬率、未實現損益
- **配置條**:台股(橙)/ 美股(藍)/ 加密(紫)佔比
- **篩選**:`全部` / `台股` / `美股` / `加密`
  - **`全部` 模式會把美股、加密換算成台幣(NT$)**,與台股統一單位方便比較
  - `美股` / `加密` 分頁則以美元($)顯示
- **排序**:市值 / 損益 / 現價 / 佔比
- **點任一持股** → 查看該檔交易明細,可新增該檔交易或刪除整檔
- 上方總覽固定,**只有下方持倉列表會捲動**

## 5. 新增與編輯交易

點投資頁右下角 **＋**(或在持股明細裡新增):

- **買入 / 賣出** 切換
- **股票代碼**:輸入後會自動完成
  - 台股:可用**代號或名稱**搜尋(例:`2330`、`台積電`)
  - 美股:用**代號**搜尋(例:`AAPL`)
  - 虛擬貨幣:用**代號或名稱**搜尋(例:`BTC`、`Bitcoin`)
- **交易日期**
- **股數 / 價格**
  - 虛擬貨幣可選**價格幣別 USD / 台幣**(避免把台幣報價誤當美元計)
- **手續費**:可選「費率 %」或「固定金額」
  - 預設費率:台股 `0.1425%`、美股 `0.08%`(選標的後自動帶入)
- **扣款 / 存入帳戶**(選填):連動資產頁現金帳戶
- 下方即時顯示「買入 / 賣出金額」與「預估手續費」

**編輯 / 刪除**:在「歷史 → 交易紀錄」或持股明細點該筆交易即可編輯;編輯視窗內也可刪除。賣出時會自動計算已實現損益,並沖銷連動帳戶。

## 7. 報表

年度 / 月度的績效彙整(資料來自每日快照)。

- **年度 / 月度** 切換;月度可選年份
- **摘要橫幅**:最新一期的本期損益、累計損益、報酬率、未實現
- **走勢圖**:預設**倉位走勢圖**(台股 / 美股 / 加密堆疊),可切換成**淨資產走勢圖**(藍線)
- **資料表**(預設由舊到新,點「期間」可切換升降序):

  | 欄位 | 說明 |
  |------|------|
  | 期間 | 年份 / 月份 |
  | 總倉位 | 期末投資市值 |
  | 本期投入 | 本期新增投入 |
  | 本期損益 / 報酬率 | 本期損益與本期報酬率 |
  | 未實現 / 已實現 | 期末未實現、本期已實現 |

- **點任一欄位標題**,上方圖表會切換成該欄位的長條圖(再點一次回走勢圖):
  - 總倉位 / 本期投入 → 藍色長條
  - 本期損益 → 正綠、負紅
  - 未實現 / 已實現 → 未實現(虛線框)+ 已實現(實心),台股正紅負綠

## 8. 雲端同步(跨裝置)

資料預設只存單一瀏覽器。要在多裝置共用同一份資料,用 **GitHub Gist 自動同步**。

### 步驟一:產生 GitHub Token

1. 開啟(已預選 `gist` 權限):
   `https://github.com/settings/tokens/new?scopes=gist&description=dives-sync`
2. **Note** 填 `dives-sync`(可改)
3. **Expiration**:想一勞永逸選 `No expiration`;較安全可設一年後
4. 確認 **`gist`** 已勾選
5. 拉到最底 → **Generate token** → 複製那串 `ghp_...`(離開頁面就看不到了)

> 請用 **classic token**(上面連結即是);只勾 `gist` 一個權限,這把鑰匙**只能讀寫你的 Gist**,碰不到程式碼或其他資料。

### 步驟二:在 App 啟用

1. 設定 → **雲端同步** → 貼上 token → **啟用**
2. 第一台有資料的裝置會把資料上傳,建立一個你帳號裡的**私人 Gist**

### 步驟三:其他裝置

- 在其他裝置 / 瀏覽器,貼上**同一組 token** → 啟用 → 自動拉下同一份資料

### 運作方式

- **開啟 App / 回到前景** → 自動拉取(遠端較新則更新)
- **新增 / 編輯 / 匯入 / 清空** → 自動推送(延遲 2 秒)
- **按 ⟳ 重新整理** → 雙向同步 + 更新報價
- 以時間戳判斷新舊,**較新的勝**

> ⚠️ 限制:同一時間在兩台裝置同時編輯,後存的會覆蓋先存的(單人跨裝置正常使用幾乎不會遇到)。Token 只存各裝置本機,不會寫進 Gist。

## 9. App 鎖定(密碼 / Face ID)

把 App 鎖起來,開啟時需驗證,保護裝置上的財務資料。

### 啟用

1. 設定 → **App 鎖定** → **啟用 App 鎖定**
2. 設定 **4–6 位數字密碼**(輸入兩次確認)
3.(裝置支援時)打開 **Face ID / Touch ID** 開關 → 完成生物辨識註冊

### 設定項目

- **變更密碼**
- **Face ID / Touch ID** 開關
- **自動鎖定**:立即 / 1 / 5 / 15 分鐘 / 1 小時(背景超過此時間回來需重新解鎖)
- **停用 App 鎖定**

### 解鎖

- 開啟 App / 逾時回前景 → 顯示鎖定畫面
- 已設定 Face ID → **自動觸發**生物辨識,看一眼即解鎖
- 也可直接輸入 PIN;Face ID 失敗時用 PIN 備援

> ℹ️ 生物辨識:iPhone 用 **Face ID / Touch ID**(需 iOS 16.4 以上、從主畫面圖示開啟);Samsung / Android 用**指紋 / 臉部解鎖**。這是「本機隱私閘門」(無後端),能擋住他人隨手翻看,非銀行等級驗證。
> **忘記密碼**:目前無法重設密碼,需清除瀏覽器網站資料(資料會一併清除),再從 CSV 備份或雲端同步還原。**請務必先備份或啟用同步。**

## 10. 資料備份與還原

設定 → **資料備份**:

- **匯出備份**:下載 `portfolio_backup_YYYY-MM-DD.csv`(含交易紀錄 + 每日快照)
- **匯入備份**:選 CSV 還原(會覆蓋現有資料)
- **重建歷史走勢圖**:用交易紀錄 + 台股／美股／加密歷史收盤,補回過去每一天的資產曲線

> CSV 格式與 iOS 原生 App 相容,可雙向搬移(**從 iOS App**:設定 → 匯出備份 → 用 AirDrop / Email 把 CSV 傳到手機 →本 App 設定 → 匯入備份)。資料只在本機,**建議定期匯出備份**。
> 走勢圖看的是「每日快照」,只有開過 App 的日子才有。輸入過去日期的交易後,按「**重建歷史走勢圖**」即可補出完整曲線。

## 12. 常見問題

**Q. 台股價格好像不是最新的?**
盤中會顯示即時價;若在收盤後或非交易時段,顯示的是當日 / 前一交易日收盤,屬正常。按 ⟳ 可手動更新。

**Q. 淨資產下方的今日漲跌是怎麼算的?**
現金與負債日內不變,所以今日淨資產漲跌等於**投資部位的今日損益**;比例是相對前一日淨資產。紅漲綠跌。

**Q. 「年」的漲幅長條圖為什麼有值?**
漲幅預設是「本期期末 − 前一期期末」;若某期間沒有前一期可比(例如資料只有一年、那唯一的年份柱),改用**該期間內的漲幅**(期末 − 期初),不會顯示 0。

**Q. 輸入了過去月份的交易,走勢圖卻沒有那段曲線?**
走勢圖看的是「每日快照」,只有你開過 App 的日子才會記錄。輸入過去日期交易後,到「設定 → 資料備份 → **重建歷史走勢圖**」,系統會用歷史收盤回推過去每一天的資產,補出完整曲線。

**Q. 不同瀏覽器 / 裝置資料不一樣?**
資料預設各瀏覽器獨立。要共用請啟用「雲端同步」(見第 8 節)。

**Q. 同步失敗?**
確認 token 是 **classic** 且勾了 `gist` 權限、未過期。錯誤訊息會顯示在同步狀態列。

**Q. 忘記 App 鎖定密碼?**
需清除瀏覽器該網站資料(資料會清空),再從 CSV 或雲端同步還原 —— 所以請先備份 / 開同步。

**Q. 更新了 App 但畫面沒變?**
把 App 完全關閉(從多工列上滑移除)再重開,Service Worker 會自動載入新版。可到「設定 → 關於」看目前版本號。

**Q. 資料安全嗎?**
資料只存你的裝置本機;啟用同步時存到你**自己 GitHub 帳號的私人 Gist**。開發者與他人都看不到你的資料。

## 13. 自行建置與部署(開發者)

原始碼:**https://github.com/WeiHao0107/Dives-web**

Dives 是**純靜態的前端 PWA**(原生 HTML / CSS / JavaScript,無框架)——**不需要任何編譯 / build 步驟**,把 `docs/` 這個資料夾用任何靜態伺服器服務出去就是完整的 App。

### 方式一:自己「加入主畫面」變成 App(最簡單,不用寫程式)

不用建置。直接用手機瀏覽器開 `https://weihao0107.github.io/Dives-web/`,依 [第 1 節](#1-安裝到手機啟用) 加入主畫面 → 圖示點開就是全螢幕 App。

### 方式二:本機執行

```bash
git clone https://github.com/WeiHao0107/Dives-web.git
cd Dives-web
python3 -m http.server 8080      # 或任何靜態伺服器,例:npx serve
# 瀏覽器開 http://localhost:8080/
```

> 若 clone 的是含 `docs/` 的來源,請改在 `docs/` 目錄下起 server(`cd docs`)。

### 方式三:部署成你自己的線上版(GitHub Pages,免費)

1. 在 GitHub 建一個 repo(例:`my-dives`),把這些檔案(`index.html`、`css/`、`js/`、`sw.js`、`manifest.webmanifest`、`icons/`…)放到 repo **根目錄**
2. 加一個空檔 **`.nojekyll`**(避免 GitHub 略過某些檔案)
3. repo → **Settings → Pages** → Source 選 **Deploy from a branch** → `main` / `root` → Save
4. 幾分鐘後即可用 `https://<你的帳號>.github.io/my-dives/` 開啟;可再依第 1 節加入主畫面

> 改版後記得同步更新 `sw.js` 的 `CACHE`(版本字串)與 `js/app.js` 的 `App.VERSION`,Service Worker 採「網路優先」會自動載入新版。

### 方式四:打包成可上架的原生 App(進階,選用)

想要能放進 App Store / Play Store 的原生殼,可用現成工具把這個 PWA 包起來,**不必改動程式**:

- **[PWABuilder](https://www.pwabuilder.com/)** — 輸入你的網址,一鍵產生 iOS / Android / Windows 專案
- **[Capacitor](https://capacitorjs.com/)** — 把 `docs/` 當 web 資產包進原生 iOS / Android 專案
- **TWA(Trusted Web Activity)** — Android 直接以你的 PWA 網址上架

> 本專案的**原生 iOS 版**以 Swift / SwiftUI 另行開發(非本 repo);此 web 版即可獨立當作完整 App 使用。
